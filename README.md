# ddd - der die das?

Manifest-V3-Extension: In der Adresszeile `ddd` tippen, Leerzeichen, dann ein Wort – Enter öffnet den deutschen Wiktionary-Eintrag.

## Installation (unpacked)

1. Chrome öffnen und `chrome://extensions` aufrufen.
2. **Entwicklermodus** aktivieren.
3. **Entpackte Erweiterung laden** und diesen Ordner wählen (mit `manifest.json`).
4. Fertig – das Omnibox-Keyword `ddd` ist aktiv.

## Nutzung

1. In die Adresszeile tippen: `ddd` und dann **Leertaste** (oder Tab).
2. Wort eingeben, z. B. `Lebenslauf`.
3. Enter → öffnet `https://de.wiktionary.org/wiki/Lebenslauf`.

Mehrere Wörter werden mit Unterstrich verknüpft (`foo bar` → `…/wiki/foo_bar`). Sonderzeichen werden URL-kodiert.
